GitHub API token

bytes.io calls GitHub's API to read languages, manifests, and commit history for each repo. Unauthenticated requests are capped at 60/hour; a personal access token raises that to 5,000/hour. The token is stored only in this browser's localStorage and is sent only to api.github.com / raw.githubusercontent.com — never to bytes.io or anywhere else. A token with no scopes (or a fine-grained, read-only, public-repos token) is enough.

Recently added

Libraries newly seen in index.json, newest first.

bytes.io has no backend, so "recently added" is tracked locally: the first time your browser sees a library in index.json, it stamps that moment and remembers it. It's a good way to spot what's new to you, but the dates are per-device, not a global publish timeline — for that, use the Atom feed, generated server-side from the index's git history.
